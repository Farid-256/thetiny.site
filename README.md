TheTinySite Clone - URL Shortener Landing Page

A fast, modern, and fully responsive landing page built as a clone of thetiny.site for an internship application. This application demonstrates clean code structure, interactive UI elements, dynamic state management, and modern styling techniques using Next.js and Tailwind CSS.

Project Overview

This project is a front-end replica of thetiny.site, designed to showcase essential features of a modern URL shortener web application. It includes dynamic features like:

Live link copy functionality with instant visual feedback (Copied!).

Interactive QR Code generator modal with image download support.

Custom Link Analytics dashboard representation with Right-to-Left (RTL) progress indicators.

Dynamic subscription tier cards and testimonials section.

Technologies Used

The project is built with modern web technologies to ensure optimal performance, scalability, and ease of maintenance:

Framework: Next.js (React App Router / Client Components)

Styling: Tailwind CSS (Utility-first CSS framework for custom responsive design)

Icons: React Icons (Includes icons from FontAwesome 6, Feather, Io5, and Tabler)

UI Notifications: React Toastify (User feedback toasts)

QR Generator: qrcode.react (Dynamic SVG to PNG QR Code generation)

Responsiveness

Yes, the application is 100% Fully Responsive.

Special attention was given to layout adaptations across different viewport sizes:

Mobile Devices (< 640px): Single-column layouts, touch-friendly buttons, responsive font sizing, and scrollable containers.

Tablets (640px - 1024px): Adapted grid structures (2-column grids) and optimized paddings.

Desktops (> 1024px): Full multi-column grid layouts (3-column pricing & features), fixed glassmorphism navigation, and balanced section proportions.

How to Run the Project

Clone the repository:

git clone https://github.com/your-username/thetiny-site-clone.git


Install dependencies:

npm install


Start the development server:

npm run dev


View in browser:
Open http://localhost:3000 in your browser.
